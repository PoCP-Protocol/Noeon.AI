# NOEON Next Manifesto v0.1

We create a language that treats intelligence as programmable structure, not hidden prompt behavior.

## Ten Commitments

1. Programs declare goals before mechanisms.
2. World models are explicit and typed.
3. Strategies are enumerable and comparable.
4. Guarantees are mandatory before irreversible actions.
5. Actions are capability-scoped and budgeted.
6. Reflection is first-class, not logging afterthought.
7. Evolution is bounded, reviewable, and reversible.
8. Confidence and provenance are universal metadata.
9. Every critical decision is explainable.
10. Language design optimizes for safety, speed, and adaptation together.

## Design Attitude

1. Prefer clarity over cleverness.
2. Prefer explicit guarantees over implicit trust.
3. Prefer observable adaptation over opaque autonomy.

## Immediate Build Objective

Implement the v0.1 core so one real workflow can:

1. Build model.
2. Compare strategy.
3. Verify guarantees.
4. Execute action.
5. Produce reflection.
6. Propose bounded evolution.

This is not a thought experiment. This is an implementation agenda.
